# Дифф без перестроек: раскладка от git-патча

## Проблема

Переключение файла коммита перестраивало дифф в несколько видимых шагов:
пустой кадр → плоский файл с первой строки → схлопывание в hunk-вид →
плашки ханков → sticky scroll. Причина: раскладка вида зависела от
асинхронного конвейера monaco (дифф в воркере ~15–100 мс, `hideUnchangedRegions`
после него, наши плашки — ещё позже, через отдельный IPC и асинхронный
`createRoot().render`), и каждая стадия прибывала отдельным кадром.

Два предыдущих подхода отвергнуты по результатам проверки на живом окне:
скрытие редактора до готовности (пустота хуже мигания) и синхронный
дифф-провайдер через подмену `diffProviderFactoryService` с импортами из
внутренностей monaco (хрупко, и не убирает все стадии).

## Оракул

GitKraken использует тот же monaco (v2-эра, дифф-воркер не подменён), но
раскладка у него никогда не ждёт monaco-вского диффа. Из минифицированного
бандла (`app.asar`, `render.bundle.js`): ханки берутся из git-патча, скрытие
неизменённого — синхронный `setHiddenAreas` на обоих редакторах, заголовки —
overlay-виджеты с синхронным `ReactDOM.render`, прокрутка — `revealFirstDiff`.
Асинхронный дифф лишь докрашивает цвета в уже стоящую раскладку.

## Решение

Единственный источник раскладки — git-патч (`commitFileHunks` /
`workingTreeHunks`), который и так грузится вместе со сторонами диффа.

- Обе половины (`diffSides` + патч) ждутся вместе (`Promise.all`); до их
  прихода на экране стоит прежний файл. Подмена — один React-коммит.
- `parseUnifiedDiff` разбирает все четыре числа `@@`-заголовка; `hiddenSpans`
  считает диапазоны вне ханков для обеих сторон.
- Скрытие — `setHiddenAreas` (рантайм-API monaco, в публичном `monaco.d.ts`
  не задекларирован; каст изолирован в `setHiddenLineSpans` в
  `entities/diff/monaco.ts`). `hideUnchangedRegions` выключен всюду — вместе
  с ним исчез и его дублирующий заголовок «N hidden lines».
- Плашки ханков — те же view zones, но содержимое рендерится порталами из
  дерева DiffView: коммитится в том же проходе, что и всё остальное, пустых
  плашек не бывает. Второго React-корня нет.
- Прокрутка синхронная: hunk-режим — к началу (первый ханк и есть верх),
  split/inline — `revealLineNearTop(первый ханк)`; без патча — публичный
  `revealFirstDiff()`.
- Sticky scroll в дифф-редакторах выключен: его обновление живёт на
  планировщике 50 мс и всплывает после кадра; у эталона его нет.

`FileHistoryView` использует ту же раскладку (общий pref режима — общее
поведение).

Цвета диффа по-прежнему приходят от воркера позже — как у эталона: они
проявляются в неподвижной раскладке и перестройкой не являются.
