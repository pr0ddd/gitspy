# Главная страница: срезы, избранное, паспорт репозитория

Дата: 2026-08-06. Согласовано по мокапу (артефакт «gitspy — Start Page»,
версия source-icons).

## Что не так сейчас

StartPage — один список недавних с плиткой-инициалами и понятием «Local»
в рейке. Нет избранного, не видно ветку и источник репозитория, действия
над строкой — только «забыть».

## Решения

**Каркас общий и не меняется:** вкладки сверху, рейка слева, карточка
справа — как во всём приложении.

**Рейка — срезы и аккаунты, а не «места».**

- Секция `Repositories`: `All` и `Favorites` — срезы одного локального
  списка. Слова «Local» нет: локальность — умолчание, её не называют.
- Секция `Accounts`: подключения хостингов (как сейчас); клик
  переключает карточку в список репозиториев хостинга с действием Clone.
- К низу рейки прижата тихая строка «Connect account…» — ведёт в
  Settings (как текущая `onConnect`).

**Шапка карточки.** Поиск — главный элемент, во всю ширину, с бейджем
⌘K (и хоткеем); ищет по текущему срезу. Справа кнопки Open / Clone /
Create.

**Строка списка** — одна линия, плотная (высота как у крупных строк
списка в теме, без плитки-инициалов):

- слот звезды (занят всегда — имена стоят ровно): у избранных горит,
  у прочих появляется по ховеру;
- иконка источника: `Icon.github` / `Icon.gitlab` / `Icon.bitbucket`
  по хосту origin, `Icon.folder` если remote нет;
- имя (medium), путь продолжением (faint, моно; на ховере строки
  поднимается до muted-foreground);
- справа: ветка (иконка + имя, muted), место под ↑↓✎ (фаза 2), время;
- ховер: время уступает место действиям — звезда, показать в Finder,
  забыть;
- `exists == false`: строка гаснет, вместо ветки бейдж missing.

**Секции.** В срезе All: `Favorites`, затем `Recent`. Срез Favorites
показывает только избранное. Пустое избранное — `InlineNote`, не пустая
секция.

## Данные

**Избранное** — флаг `favorite: bool` в `RecentRepo` (`recent.rs`,
тот же файл хранения). Новая команда переключения возвращает
обновлённый список, как `forget`.

**Паспорт репозитория** — новая команда: для списка путей отдаёт
`{ path, branch, host }`:

- `branch` — текущая ветка от системного git (`symbolic-ref`), null в
  detached/пустом репозитории;
- `host` — вид хостинга по `remote.origin.url` через
  `gitspy-hosts::host_of_url`, null без remote.

Команда вызывается со StartPage после первого рендера: страница
рисуется сразу по `recent`, чипы веток и иконки источника дозаполняются.
Ошибка паспорта по одному пути не валит остальные.

**Фаза 2 (отдельная спека, не сейчас):** ahead/behind и счётчик
незакоммиченного в той же строке; место заложено.

## Канон исполнения

Никаких частных стилей: строки — `ListRow`-подход из `parts.tsx` (или
новая часть в словаре, если существующие не ложатся), заголовки секций —
`SectionHeader`, рейка — `NavItem`, кнопки — варианты `cva`, все цвета —
токены темы. Иконки — только через `src/icons.ts`. Тексты — ключи i18n.

## Тесты

- Rust `recent.rs`: избранное переживает перезапись файла; toggle
  двунаправленный; forget избранного удаляет запись.
- Rust паспорт: на фикстуре настоящего git ветка совпадает с
  `git symbolic-ref --short HEAD`; без remote host пуст; несуществующий
  путь не валит соседей.
- Фронтенд: разбиение списка на срезы/секции и фильтр — чистые функции
  с тестами (избранные не дублируются в Recent; фильтр режет обе
  секции; пустые состояния).
