# Терминал

**Дата:** 2026-08-07, переписано 2026-08-14
**Статус:** принято
**Основание:** пять кликабельных мокапов на токенах приложения
(`.superpowers/brainstorm/25280-1786098871/`), спайк стека в настоящем окне
Tauri с замерами.

## 1. Замысел

Внизу репо-вкладки живёт один терминал — обычный отличный терминал: PTY,
байты, вкладки. Он не знает, что внутри запущено: ни агентских статусов, ни
разбора вывода, ни чипов. Всё, что он умеет, стоит на том, что программа
сама сообщает через OSC.

**Агентские сессии вырезаны 2026-08-14.** Был второй слой — ленты
AI-агентов поверх Agent Client Protocol: крейт `gitspy-acp`, команды
`acp_*`, слайсы `entities/agent` и `features/agent`, чекпоинты в
`refs/gitspy/checkpoints`, полноэкранная раскладка дока с колонкой
контекста. Всё это удалено под корень по решению заказчика: приложение —
клиент git, и остаться должен один терминал, работающий эталонно. Агент
запускается в нём как любая другая программа — это и было запасным
выходом с самого начала.

## 2. Принятые решения

### Раскладка

Центр репо-вкладки — стопка видов: граф / диф / файл сменяют друг друга.
Терминал — нижний док поверх этой стопки, высота тянется за разделитель.
Ни правой колонки, ни полноэкранного режима: у дока одно место, и спорить
о нём нечему.

Док открывается кнопкой на панели действий и по `Cmd+\``. Открытие —
уже высказанное намерение, поэтому док заводит сессию сам, а не встречает
человека второй кнопкой. Закрытая последняя вкладка — тоже намерение:
новую за человека никто не открывает.

### Сессии

Вкладки в шапке дока: иконка, живой заголовок, точка статуса команды.
Заголовок задаёт сама программа через OSC 0/2, поэтому вкладки читаются
как «кто чем занят» без единой догадки с нашей стороны. Сессии живут по
репозиториям: чужой репозиторий своих вкладок не приносит.

Кнопка «+» открывает логин-шелл. Профиль — это просто сохранённая команда
запуска (`zsh`, `claude`, `npm run app`); пока профиль один, стрелки
выбора в шапке нет — меню из одного пункта это лишний клик и лишний
элемент.

### Терминал

- PTY со **живым** окружением: логин-шелл пользователя, его PATH и конфиги,
  cwd по репозиторию или worktree. Это противоположность `gitspy-exec`,
  где окружение намеренно обезврежено; поэтому отдельный крейт
  `crates/gitspy-term`, а не расширение exec.
- Кликабельные ссылки: URL — в браузер; путь файла (включая `file:12:5`) —
  диф или файл в центре; хеш коммита — подсветка коммита в графе.
  Реализация — свой `ILinkProvider` xterm.js плюс штатный аддон для URL.
- Shell integration: свой сниппет для zsh с OSC 133 — границы команд,
  статус упавшей команды; OSC 7 — трекинг cwd.
- Размер: подгон идёт раз в кадр по `ResizeObserver`, в том числе пока
  разделитель зажат. Терминал, застывший до конца жеста, показывает старую
  сетку под новой высотой — это видно и читается как поломка.
- Цвета ANSI и всё оформление — из токенов `src/index.css` через
  `getComputedStyle`, как это уже делает canvas графа.

## 3. Стек и замеры

Спайк в настоящем окне Tauri (`VITE_SPIKE=term`, второй экземпляр на
отдельном порту), все проверки автоматические, числа из stdout:

| Проверка | Результат |
|---|---|
| PTY: `test -t 1` в zsh `-il`, cwd репозитория | TTY настоящий |
| `Channel` + `InvokeResponseBody::Raw` | байты доезжают как ArrayBuffer |
| WebGL-рендер xterm.js в WKWebView | поднялся |
| OSC 0/2 → `onTitleChange` | долетает |
| resize → `stty size` | ровно 30x120 |
| `cat` 10 МБ сквозь весь тракт | 1100 мс ≈ 9.3 МБ/с, xterm разгребает с нулевым отставанием |
| кадры под потоком | одна дыра 376 мс за залп |

Выбор:

| Слой | Библиотека | Примечание |
|---|---|---|
| Эмулятор | `@xterm/xterm` + `addon-webgl`, `fit`, `search`, `serialize`, `clipboard`, `unicode11` | движок терминала VS Code; свой эмулятор — не наша война |
| Ссылки | свой `ILinkProvider` + `addon-web-links` | пути и хеши — наша логика |
| OSC | `registerOscHandler` | 133 / 7 / 0-2 |
| PTY | `portable-pty` 0.9 | крейт WezTerm |
| Транспорт | Tauri `Channel`, сырые байты | вывод копится и отдаётся раз в кадр; ack-флоу-контроль как у VS Code — это же закрывает дыру 376 мс |

Zed как источник: не терминал (их скорость — из нативного GPUI, у нас
webview, перенос не работает), а `alacritty_terminal` как кандидат для
брокера персистентности.

## 4. Границы

- `crates/gitspy-term` — PTY, сессии, живое окружение. Не знает про Tauri.
- `src-tauri` — команды `term_*` и каналы.
- Фронт по FSD: `entities/terminal` (обёртка xterm, модель сессии, тема),
  `features/terminal` (профили, ссылки, OSC), `widgets/TerminalDock`.
- Тексты — ключи i18n, ошибки — код и параметры, как везде.

## 5. Не делаем

IDE-функции (LSP-редактор, отладчик); разбор вывода программ; агентские
ленты, разрешения и чекпоинты — вырезаны и не возвращаются; персистентность
сессий между запусками.
