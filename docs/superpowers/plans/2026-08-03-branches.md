# Ветки: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ветки в сайдбаре деревом папок, со стрелками «впереди / позади», переходом двойным щелчком и созданием локальной из удалённой; состояние репозитория при этом переезжает с gix на системный git.

**Architecture:** Владение разделено по фактам. `gix` оставляет себе объекты навалом — обход истории и метаданные. Всё состояние репозитория — ссылки, `%(HEAD)`, upstream, счётчики, стеш — приходит одним разбором вывода `git for-each-ref` в `gitspy-exec`. `gitspy-repo` перестаёт знать, что такое ветка: он принимает список интересных oid и возвращает их номера строк.

**Tech Stack:** Rust (gix 0.86, ts-rs), Tauri 2, React 19, TypeScript, vitest, Tailwind + shadcn.

**Основание:** `docs/superpowers/specs/2026-08-03-branches-design.md`.

- **Комментариев в коде нет** — ни `//`, ни `///`, ни `//!`, ни `/* */`. Объяснение живёт в имени функции, имени теста и сообщении `assert`.
- **Идентификаторы английские, проза русская.** Имена тестов английские, сообщения `assert` русские.
- **Сообщения коммитов английские, целиком, без трейлеров.**
- **Строк для пользователя в коде нет** — только ключи i18n; каждый новый ключ добавляется и в `src/locales/en/`, и в `src/locales/ru/`.

- **Иконки — только через `src/icons.ts`**, не из `lucide-react` напрямую.
- Проверки перед каждым коммитом: `cargo fmt --all`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, `npm run build`.

```rust
pub const FORMAT: &str = "%(HEAD)%09%(refname)%09%(objecttype)%09%(objectname)%09%(*objecttype)%09%(*objectname)%09%(upstream:short)%09%(upstream:track,nobracket)";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RefKind {
    LocalBranch,
    RemoteBranch,
    Tag,
    Stash,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RefLine {
    pub name: String,
    pub full_name: String,
    pub kind: RefKind,
    pub oid: String,
    pub is_head: bool,
    pub upstream: Option<String>,
    pub ahead: u32,
    pub behind: u32,
    pub gone: bool,
}

pub fn parse_track(raw: &str) -> (u32, u32, bool) {
    let text = raw.trim();
    if text == "gone" {
        return (0, 0, true);
    }
    let mut ahead = 0;
    let mut behind = 0;
    for part in text.split(',') {
        let mut words = part.split_whitespace();
        match (words.next(), words.next().and_then(|n| n.parse().ok())) {
            (Some("ahead"), Some(count)) => ahead = count,
            (Some("behind"), Some(count)) => behind = count,
            _ => {}
        }
    }
    (ahead, behind, false)
}

fn classify(full_name: &str) -> Option<(String, RefKind)> {
    if let Some(rest) = full_name.strip_prefix("refs/heads/") {
        return Some((rest.to_string(), RefKind::LocalBranch));
    }
    if let Some(rest) = full_name.strip_prefix("refs/remotes/") {
        if rest == "HEAD" || rest.ends_with("/HEAD") {
            return None;
        }
        return Some((rest.to_string(), RefKind::RemoteBranch));
    }
    full_name
        .strip_prefix("refs/tags/")
        .map(|rest| (rest.to_string(), RefKind::Tag))
}

fn effective<'a>(direct: &'a str, peeled: &'a str) -> &'a str {
    if peeled.is_empty() {
        direct
    } else {
        peeled
    }
}

pub fn mentions_stash(raw: &str) -> bool {
    raw.lines()
        .filter_map(|line| line.split('\t').nth(1))
        .any(|name| name == "refs/stash")
}

pub fn parse_for_each_ref(raw: &str) -> Vec<RefLine> {
    raw.lines()
        .filter_map(|line| {
            let fields: Vec<&str> = line.split('\t').collect();
            if fields.len() < 8 {
                return None;
            }
            let full_name = fields[1];
            let (name, kind) = classify(full_name)?;
            if effective(fields[2], fields[4]) != "commit" {
                return None;
            }
            let upstream = fields[6];
            let (ahead, behind, gone) = parse_track(fields[7]);
            Some(RefLine {
                name,
                full_name: full_name.to_string(),
                kind,
                oid: effective(fields[3], fields[5]).to_string(),
                is_head: fields[0].trim() == "*",
                upstream: (!upstream.is_empty()).then(|| upstream.to_string()),
                ahead,
                behind,
                gone,
            })
        })
        .collect()
}

pub fn parse_stash_list(raw: &str) -> Vec<RefLine> {
    raw.lines()
        .filter_map(|line| {
            let mut fields = line.split('\t');
            let oid = fields.next()?;
            let name = fields.next()?;
            if oid.is_empty() || name.is_empty() {
                return None;
            }
            Some(RefLine {
                name: name.to_string(),
                full_name: "refs/stash".to_string(),
                kind: RefKind::Stash,
                oid: oid.to_string(),
                is_head: false,
                upstream: None,
                ahead: 0,
                behind: 0,
                gone: false,
            })
        })
        .collect()
}
```

```rust
    pub fn refs(&self, repo: &Path) -> Result<Vec<refs::RefLine>, Error> {
        let format = format!("--format={}", refs::FORMAT);
        let raw = self.read(repo, &["for-each-ref", &format])?;
        let mut found = refs::parse_for_each_ref(&raw);

        if refs::mentions_stash(&raw) {
            let listed = self.read(repo, &["stash", "list", "--format=%H%x09%gd%x09%gs"])?;
            found.extend(refs::parse_stash_list(&listed));
        }
```

```ts
import type { RefView } from './types';

export type TreeNode =
  | { kind: 'folder'; name: string; path: string; children: TreeNode[] }
  | { kind: 'ref'; name: string; path: string; ref: RefView };

type Draft = {
  folders: Map<string, Draft>;
  refs: RefView[];
};

const emptyDraft = (): Draft => ({ folders: new Map(), refs: [] });

const place = (draft: Draft, segments: string[], ref: RefView) => {
  if (segments.length === 1) {
    draft.refs.push(ref);
    return;
  }
  const [head, ...rest] = segments;
  const next = draft.folders.get(head) ?? emptyDraft();
  draft.folders.set(head, next);
  place(next, rest, ref);
};

const collate = new Intl.Collator(undefined, { numeric: true, sensitivity: 'base' });

const harvest = (draft: Draft, prefix: string): TreeNode[] => {
  const folders: TreeNode[] = [...draft.folders.entries()].map(([name, child]) => {
    const path = prefix ? `${prefix}/${name}` : name;
    return { kind: 'folder', name, path, children: harvest(child, path) };
  });

  const leaves: TreeNode[] = draft.refs.map((ref) => ({
    kind: 'ref',
    name: ref.name.slice(ref.name.lastIndexOf('/') + 1),
    path: ref.name,
    ref,
  }));

  return [...folders, ...leaves].sort((a, b) => collate.compare(a.name, b.name));
};

export const buildRefTree = (refs: RefView[]): TreeNode[] => {
  const root = emptyDraft();
  for (const ref of refs) place(root, ref.name.split('/'), ref);
  return harvest(root, '');
};

export const openPathsFor = (tree: TreeNode[], needle: string): Set<string> => {
  const query = needle.trim().toLowerCase();
  const open = new Set<string>();
  if (!query) return open;

  const visit = (nodes: TreeNode[]): boolean =>
    nodes.reduce((found, node) => {
      if (node.kind === 'ref') {
        return node.path.toLowerCase().includes(query) || found;
      }
      const inside = visit(node.children);
      if (inside) open.add(node.path);
      return inside || found;
    }, false);

  visit(tree);
  return open;
};
```

```rust
pub fn start(app: tauri::AppHandle, minutes: u64) {
    if minutes == 0 {
        return;
    }
    std::thread::spawn(move || loop {
        std::thread::sleep(interval(minutes));
        sweep(&app);
    });
}

fn sweep(app: &tauri::AppHandle) {
    use tauri::Manager;
    let state = app.state::<crate::state::AppState>();

    let Ok(git) = state.git() else {
        return;
    };
    let Ok(open) = state.repos.lock() else {
        return;
    };
    let paths: Vec<std::path::PathBuf> = open.values().map(|r| r.path.clone()).collect();
    drop(open);

    for path in paths {
        let key = path.display().to_string();
        let lane = state.queue.lane(&key);
        let busy = lane.try_lock().is_err();
        if should_skip(busy, !git.remotes(&path).is_empty()) {
            continue;
        }

        let cancel = Cancel::new();
        state.remember_autofetch(&key, cancel.clone());
        let held = lane.lock();
        let _ = crate::operations::run(
            &git,
            &path,
            crate::operations::Operation::Fetch,
            None,
            &cancel,
            &mut |_| {},
        );
        drop(held);
        state.cancel_autofetch(&key);
    }
}
```

`Cancel` уже реализует `Clone` — проверить и добавить, если нет.

`start` вызывается в `setup` приложения в `src-tauri/src/main.rs` со значением из настроек.

**Отмена операцией человека.** В `run_operation`, до взятия полосы:

```rust
    state.cancel_autofetch(&repo);
```

Без этой строки правило «операция человека отменяет фоновый фетч» остаётся написанным в спеке и не выполненным в коде: полоса уже занята фоновым фетчем, и человек ждёт, пока тот доработает, — вплоть до восемнадцатиминутного таймаута DNS.

Фоновый фетч учётных данных не получает (`None` вместо `Credential`): молчаливый запрос пароля в фоне человек не увидит, а операция повиснет. Приватный репозиторий без готового доступа просто не обновится сам — это честнее, чем висеть.

## Порядок и зависимости

Части идут строго по номерам: задачи 5–6 читают поля, которые появляются в 4; задача 8 зовёт операцию из 7; задача 10 без 9 вредит.

Внутри первой части порядок обязателен по другой причине: **тесты на ссылки переезжают в задаче 2, а gix-код удаляется в задаче 3.** Наоборот делать нельзя — тогда между коммитами существует состояние, где поведение не проверяется ничем.

## Готовность

- Ветки в сайдбаре нарисованы деревом; цепочка из пяти папок даёт пять строк.
- У ветки с upstream видны стрелки, совпадающие с `git rev-list --left-right --count`; у ветки без upstream не видно ничего.
- Одинарный щелчок везёт граф на коммит ветки, двойной переключает.
- Двойной щелчок по удалённой ветке, которой нет локально, создаёт отслеживающую и переходит на неё; по той, которая есть, — просто переходит.
- Переключение при грязном дереве даёт тост, а не тишину.
- Коммит, сделанный в другом клоне и запушенный, появляется в графе сам, без единого нажатия.
- Пустой фетч не вызывает перечитывания истории.
- `cargo test`, `npm run build`, `cargo clippy --all-targets -- -D warnings` зелёные.
