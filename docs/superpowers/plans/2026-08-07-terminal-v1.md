# Терминал v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Встроенный терминал: PTY-сессии с живым окружением, док снизу со списком сессий справа, кликабельные пути/хеши, живые заголовки, профили-команды.

**Architecture:** Rust-крейт `gitspy-term` владеет PTY (portable-pty); `src-tauri/src/term.rs` — команды `term_*` и поток байтов через `Channel` с батчингом по кадру и ack-флоу-контролем; фронт — `entities/terminal` (xterm-обёртка, стор, тема), `features/terminal` (ссылки, OSC, профили), `widgets/TerminalDock`. Спека: `docs/superpowers/specs/2026-08-07-terminal-acp-design.md`.

**Tech Stack:** `@xterm/xterm` + `addon-webgl/fit/serialize/search/web-links`, `portable-pty` 0.9, Tauri 2 `Channel` (`InvokeResponseBody::Raw`), zustand.

fn collect(spec: SpawnSpec) -> String {
    let (tx, rx) = mpsc::channel::<Vec<u8>>();
    let mut session = PtySession::spawn(
        spec,
        Box::new(move |bytes| {
            let _ = tx.send(bytes.to_vec());
        }),
    )
    .expect("сессия должна запускаться");
    let mut out = Vec::new();
    while let Ok(chunk) = rx.recv_timeout(Duration::from_secs(5)) {
        out.extend(chunk);
        if String::from_utf8_lossy(&out).contains("MARK_") {
            break;
        }
    }
    session.kill();
    String::from_utf8_lossy(&out).into_owned()
}

```rust
use portable_pty::{native_pty_system, CommandBuilder, PtySize};
use std::io::{Read, Write};
use std::path::PathBuf;

pub struct SpawnSpec {
    pub command: Option<String>,
    pub cwd: PathBuf,
    pub cols: u16,
    pub rows: u16,
    pub shell_integration: bool,
}

pub struct PtySession {
    writer: Box<dyn Write + Send>,
    master: Box<dyn portable_pty::MasterPty + Send>,
    child: Box<dyn portable_pty::Child + Send + Sync>,
}

impl PtySession {
    pub fn spawn(
        spec: SpawnSpec,
        mut on_bytes: Box<dyn FnMut(&[u8]) + Send>,
    ) -> Result<PtySession, String> {
        let pty = native_pty_system();
        let pair = pty
            .openpty(PtySize {
                rows: spec.rows,
                cols: spec.cols,
                pixel_width: 0,
                pixel_height: 0,
            })
            .map_err(|e| e.to_string())?;
        let mut cmd = CommandBuilder::new("/bin/zsh");
        match &spec.command {
            Some(line) => cmd.args(["-ilc", line]),
            None => cmd.args(["-il"]),
        };
        cmd.cwd(&spec.cwd);
        let child = pair.slave.spawn_command(cmd).map_err(|e| e.to_string())?;
        drop(pair.slave);
        let mut reader = pair.master.try_clone_reader().map_err(|e| e.to_string())?;
        let writer = pair.master.take_writer().map_err(|e| e.to_string())?;
        std::thread::spawn(move || {
            let mut buf = [0u8; 65536];
            loop {
                match reader.read(&mut buf) {
                    Ok(0) | Err(_) => break,
                    Ok(n) => on_bytes(&buf[..n]),
                }
            }
        });
        Ok(PtySession { writer, master: pair.master, child })
    }

    pub fn write(&mut self, data: &[u8]) -> Result<(), String> {
        self.writer.write_all(data).map_err(|e| e.to_string())
    }

    pub fn resize(&mut self, cols: u16, rows: u16) -> Result<(), String> {
        self.master
            .resize(PtySize { rows, cols, pixel_width: 0, pixel_height: 0 })
            .map_err(|e| e.to_string())
    }

    pub fn kill(&mut self) {
        let _ = self.child.kill();
    }
}
```

`src-tauri/src/term_batch.rs` (над тестами):

```rust
use std::time::{Duration, Instant};

pub struct Batcher {
    buf: Vec<u8>,
    first_at: Option<Instant>,
    max_bytes: usize,
    max_wait: Duration,
}

impl Batcher {
    pub fn new(max_bytes: usize, max_wait: Duration) -> Batcher {
        Batcher { buf: Vec::new(), first_at: None, max_bytes, max_wait }
    }

    pub fn push(&mut self, bytes: &[u8], now: Instant) -> Option<Vec<u8>> {
        if self.buf.is_empty() {
            self.first_at = Some(now);
        }
        self.buf.extend_from_slice(bytes);
        let due = self.first_at.is_some_and(|t| now.duration_since(t) >= self.max_wait);
        if self.buf.len() >= self.max_bytes || due {
            return self.flush();
        }
        None
    }

    pub fn flush(&mut self) -> Option<Vec<u8>> {
        if self.buf.is_empty() {
            return None;
        }
        self.first_at = None;
        Some(std::mem::take(&mut self.buf))
    }
}
```
