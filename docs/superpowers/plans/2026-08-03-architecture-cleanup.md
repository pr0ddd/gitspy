# Уборка двух прихожих: план

> Источник: архитектурный разбор 2026-08-03. Три пункта, до новых фич.

**Цель:** `App.tsx` — снова композиция, `main.rs` — снова сборка; логика,
осевшая в них, переезжает туда, где её проверяют тесты.

---

### Задача 1. Сессии фронтенда — редьюсер с тестами

**Файлы:** `src/session.ts`, `src/session.test.ts`, `src/App.tsx`

Сегодня `App` держит 17 `useState` и руками жонглирует массивом сессий:
открытие с дедупликацией, закрытие с выбором соседней вкладки, подтяжка
выделения после перечитывания. Всё это — чистые переходы состояния, которые
никто не тестирует, потому что они размазаны по колбэкам.

- [x] Тип `SessionsState { sessions, active }` и редьюсер переходов:
  `open`, `close`, `activate`, `loaded`, `failed`, `select`, `worktrees`
- [x] Тесты на переходы: открытие существующего не плодит вкладку; закрытие
  активной выбирает соседнюю; `loaded` подтягивает выделение под новую длину;
  `failed` убирает сессию
- [x] `App` на `useReducer`; асинхронщина остаётся в `App`, но колбэки — тонкие
- [x] Кэш окон (`RowCache`) и `redraw` не трогаются: это протокол данных графа,
  не сессий, и мешать их в один переезд нельзя

## Второй заход: пять некрасивостей из разбора

- [x] **События генерируются из Rust.** `events.rs` пишет `src/generated/events.ts`
  тестом — тем же путём, что и типы; `boundary:check` теперь сторожит и имена.
  Тест держит правило: у каждого события есть пространство имён.
- [x] **`gitspy-repo` разрезан:** `model` (типы и переходы), `read` (чтение через
  gix), `worktrees`; `lib.rs` — 127 строк реэкспортов. Публичный API не менялся.
- [x] **Протокол данных графа явный:** `useRepoData` — единственный владелец
  `RowCache` и версии; мутация без сигнала стала невозможной. Попутно закрыта
  утечка: кэш закрытой вкладки теперь выбрасывается.
- [x] **Поиск — свой хук** (`useCommitSearch`): запрос, дебаунс, переходы.
  `App`: 476 → 390 строк, 17 → 11 `useState`.
- [x] **Маршрутизация указателя — чистая функция** `pointerTarget` с тестами
  приоритетов (минимапа > граница в шапке > полоса прокрутки > строка);
  `hitTest` удалён.

Осознанно не сделано: три состояния диалогов в `App` не сгруппированы — у них
нет переходов, которые можно было бы тестировать, union дал бы форму без пользы.
